### 💼 Job & Internship Portal

A full-stack web application designed to connect students with recruiters and help students discover job and internship opportunities.

**Key Features:**
- User registration and login with JWT authentication.
- Role-based access for Students, Recruiters, and Admins.
- Student and recruiter profile management.
- Job posting, updating, viewing, and deletion.
- Smart job search with filters for job title, location, job type, and skills.
- Job application submission and application tracking.
- Recruiter-side application management.

**Tech Stack:**
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** JSON Web Token (JWT)
- **Tools:** VS Code, Postman, Git & GitHub

**What I Learned:**
- Building RESTful APIs using Node.js and Express.js.
- Connecting a backend application with a MySQL database.
- Implementing authentication and role-based authorization.
- Testing APIs using Postman.
- Managing project code using Git and GitHub.
